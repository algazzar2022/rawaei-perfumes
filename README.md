# مشروع متجر روائع للعطور – RAWAEI PERFUMES

> **متجر إلكتروني فاخر ومتكامل للعطور والعود الملكي مع لوحة تحكم إدارية مستقلة.**
> مصمم وفق أرقى معايير تجربة المستخدم وأسلوب **Luxury Glassmorphism**، مع ربط كامل بقاعدة البيانات عبر **Prisma ORM** ودعم كامل للغتين العربية (RTL) والإنجليزية بخط **Cairo**.

---

## 🌟 نظرة عامة على المشروع

تم بناء المشروع باستخدام أحدث تقنيات **Next.js 14 (App Router)** لتوفير أداء فائق وسرعة تحميل استثنائية، مع تصميم احترافي مخصص غير مكرر يعكس هوية عطور النخبة.

### ألوان الهوية البصرية (Luxury Palette):
* **Primary Gold:** `#C49A45`
* **Dark Gold:** `#98702B`
* **White:** `#FFFFFF`
* **Black:** `#171717`
* **Ivory:** `#F8F5EF`
* **Accents:** Dark Charcoal `#0D0D0D`, Subtle Translucent Gold Borders, Backdrop Blur.

## 🛠️ التقنيات المستخدمة

* **الإطار البرمجي:** Next.js 14 (App Router, Server & Client Components)
* **لغة البرمجة:** TypeScript
* **تنسيق الواجهات:** Tailwind CSS (Luxury Glassmorphism Custom Utilities)
* **قاعدة البيانات وORM:** Prisma ORM (مهيأة ومختبرة بنظام SQLite محلياً بدون إعدادات معقدة، وقابلة للتحويل إلى PostgreSQL بضغطة زر)
* **الحركات والتأثيرات:** Framer Motion
* **الأيقونات:** Lucide Icons
* **التشفير والمصادقة:** Bcryptjs & JWT Auth Tokens
* **الخطوط:** Cairo للغة العربية، Playfair Display للإنجليزية

## 💎 أقسام ومميزات المتجر الإلكتروني (Storefront)

1. **الهيدر الزجاجي (Sticky Glass Header):**
   * اللوجو الملكي لروائع للعطور.
   * مربع بحث مركزي ذكي يبحث لحظياً في كافة العطور مع قائمة نتائج منسدلة فورية بصور المنتجات وأسعارها.
   * أيقونة حقيبة التسوق مع عداد تفاعلي يفتح درج السلة المنزلق (Cart Drawer).
   * زر الحساب والدخول السريع للوحة التحكم.
   * محول اللغة الفوري (عربي / English) مع دعم اتجاه RTL/LTR التلقائي.
   * قائمة تنقل واضحة لأقسام المتجر والتصنيفات.
   * شريط الإعلانات العلوي المخصص للعروض والشحن المجاني.

2. **البانر الرئيسي (Hero Banner):**
   * يدعم **3 أوضاع قابلة للتبديل من لوحة التحكم**:
     1. **صورة ثابتة (Static Image):** صور مستقلة للكمبيوتر والموبايل بدقة عالية وتناسب تلقائي بدون تشويه.
     2. **سلايد شو (Slideshow):** شرائح متعددة مع تحكم بمدة العرض بالثواني، نقاط التنقل، أزرار الأسهم، وروابط التحويل.
     3. **فيديو (Video):** فيديو سنيمائي يعمل تلقائياً وبشكل متكرر مع طبقة زجاجية داكنة.

3. **التصنيفات الستة الرئيسية (Core Categories):**
   1. **العطور (Perfumes)**
   2. **البخور والعود (Incense & Oud)**
   3. **المجموعات والهدايا (Sets & Gifts)**
   4. **معطرات المنزل (Home Fragrances)**
   5. **البادي سبلاش (Body Splash)**
   6. **المخمريات (Makhmariyat)**
   * كل تصنيف يحتوي على الاسم بالعربية والإنجليزية، صورة عالية الجودة، أيقونة مخصصة، وصف، وحالة تفعيل.

4. **أقسام العطور الحصرية (Gender Collections):**
   * **For Him (عطور رجالية)**: صفحة مستقلة `/perfumes/for-him`
   * **For Her (عطور نسائية)**: صفحة مستقلة `/perfumes/for-her`
   * **Unisex (عطور للجنسين)**: صفحة مستقلة `/perfumes/unisex`
   * **فلاتر تفاعلية كاملة:**
     * السعر من وإلى (Price Range).
     * حجم الزجاجة بالملليلتر (50ml, 75ml, 100ml, 150ml, 200ml).
     * الترتيب: الأحدث، السعر تصاعدياً، السعر تنازلياً، والأكثر مبيعاً.

5. **المنتجات المميزة (Featured Products):**
   * قسم مخصص في الصفحة الرئيسية يتم التحكم به يدوياً من لوحة التحكم (اختيار المنتجات، ترتيبها، تغيير العنوان، التحكم بعدد المنتجات المعروضة، أو إخفاء القسم بالكامل).

6. **البانرات الإعلانية الترويجية:**
   * بانر عريض رئيسي وبانران صغيران بجواره على الكمبيوتر بتناسب هندسي دقيق، وترتيب متجاوب على الموبايل، قابلة للتحكم بالكامل من لوحة الإدارة.

7. **صفحة تفاصيل العطر (Product Detail Page):**
   * معرض صور عالي الجودة مع مصغرات للتنقل.
   * محدد أحجام الزجاجة (50 مل، 100 مل، 150 مل) وتحديث السعر تلقائياً.
   * بطاقات الهرم العطري: الافتتاحية (Top Notes)، قلب العطر (Heart Notes)، القاعدة (Base Notes)، وثبات وفوحان العطر.
   * إضافة سريعة للسلة وشراء فوري.
   * اقتراحات عطور مشابهة.

8. **السلة والدفع الذكي (Cart & Checkout):**
   * درج سلة زجاجي جانبي (Cart Drawer) + صفحة سلة مستقلة `/cart`.
   * تطبيق أكواد الخصم والتحقق منها لحظياً من قاعدة البيانات (مثل `WELCOME10`).
   * احتساب الشحن المجاني التلقائي للطلبات فوق 350 ريال.
   * صفحة دفع متكاملة مع تسجيل بيانات العميل، المدينة، العنوان، وطرق الدفع (الدفع عند الاستلام COD، مدى، تابي).
   * صفحة نجاح الطلب مع رقم تتبع الطلب (مثل `RW-2026-XXXX`)، وتفاصيل الفاتورة الرسمية وزر لطباعتها.

9. **الفوتر الفاخر (Luxury Footer):**
   * شعار المتجر، نبذة تعريفية، روابط التصنيفات والأقسام، وسائل التواصل، روابط سياسات المتجر، والعبارة الرسمية المطلوبة:

## 🎛️ لوحة التحكم الإدارية (16 وحدة متكاملة)

1. **Dashboard والإحصائيات:** إجمالي المبيعات، الطلبات، المنتجات، العملاء، تفصيل حالات الطلبات، أحدث العمليات، وتنبيهات انخفاض المخزون.
2. **إدارة المنتجات (Products):** إضافة وتعديل وحذف العطور، رفع الصور، تحديد الأسعار وخصوماتها، النوتات العطرية، والأحجام.
3. **إدارة التصنيفات (Categories):** التحكم بالتصنيفات الستة، الصور، والأوصاف.
4. **إدارة أقسام العطور:** متابعة أقسام For Him وFor Her وUnisex.
5. **إدارة البانرات والسلايدر والفيديو:** تبديل أوضاع العرض (Static, Slideshow, Video)، تحديد مدة الشرائح، الروابط، وإدارة البانرات الإعلانية.
6. **إدارة المنتجات المميزة (Featured):** اختيار العطور يدوياً، إعادة ترتيبها، وتغيير عناوين القسم.
7. **إدارة الطلبات (Orders):** استعراض الطلبات وفلترتها، تحديث حالات الشحن (Pending, Processing, Shipped, Delivered, Cancelled)، وحالة الدفع.
8. **إدارة العملاء (Customers):** سجل المشترين وإجمالي إنفاقهم.
9. **إدارة المخزون (Inventory):** متابعة كميات المستودع وتحديثها السريع مع تنبيهات النفاذ.
10. **إدارة الكوبونات والخصومات (Coupons):** إنشاء أكواد خصم بنسبة مئوية أو قيمة ثابتة وحد أدنى للطلب.
11. **إدارة صفحات الموقع (CMS):** تعديل صفحات من نحن، سياسة الخصوصية، الشروط، والشحن.
12. **إدارة إعدادات SEO:** الميتا تاج، الوصف، الكلمات المفتاحية، وكود Google Analytics.
13. **إدارة وسائل الشحن والدفع:** تحديد تكاليف الشحن، حد الشحن المجاني، ومدة التوصيل.
14. **المستخدمين والصلاحيات (Users & Roles):** إضافة مدراء وموظفين وتحديد صلاحياتهم.
15. **إعدادات الهوية البصرية:** مراجعة لوحة الألوان المعتمدة وشريط الإعلانات العلوي.
16. **إعدادات المتجر العامة:** اسم المتجر، الهاتف، الواتساب، العملة (SAR)، نسبة الضريبة، وروابط السوشيال ميديا.

## 🚀 تشغيل المشروع محلياً

```bash
# 1. تثبيت الحزم والمكتبات
npm install

# 2. إنشاء وتحديث جداول قاعدة البيانات
npm run db:push

# 3. تغذية قاعدة البيانات بالبيانات الملكية الافتراضية والمدير
npm run db:seed

# 4. تشغيل خادم التطوير
npm run dev
```

افتح المتصفح على: `http://localhost:3000`

### التحويل إلى PostgreSQL (اختياري عند النشر السحابي):
1. في ملف `prisma/schema.prisma`، غيّر:
   ```prisma
   datasource db {
     provider = "postgresql"
     url      = env("DATABASE_URL")
   }
   ```
2. في ملف `.env`، ضع رابط الاتصال بقاعدة بيانات PostgreSQL:
   ```env
   DATABASE_URL="postgresql://user:password@localhost:5432/rawaei_db?schema=public"
   ```
3. نفّذ:
   ```bash
   npx prisma db push
   node prisma/seed.js
   ```
